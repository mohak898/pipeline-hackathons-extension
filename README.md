Project Dossier: Hackathon Pipeline Tracker (HPT)Internal Code-name: Stealth-Sync v4.0 Architecture: Chrome MV3 + Firebase + Next.js PWA1. Executive SummaryThe Hackathon Pipeline Tracker (HPT) is a professional-grade ecosystem designed for startup teams to centralize, track, and visualize hackathon deadlines in real-time. It eliminates manual data entry by "eavesdropping" on public hackathon platforms, syncing that data to a global cloud, and generating shareable, live-updating dashboards for team collaboration.2. The Core ProblemStartup teams (like Hikity) often miss critical hackathon deadlines because information is fragmented across multiple platforms (Devfolio, Unstop, Devpost).Manual Tracking is slow and prone to human error.Active Scraping (bots) often triggers security bans (Cloudflare Error 1015).Fragmented Data means the marketing team, developers, and leads aren't looking at the same timeline.3. The Solution: A Two-Part EcosystemHPT solves this with a two-pronged technical approach:Part A: The Stealth Chrome ExtensionA passive "listener" that sits in your browser. Unlike traditional scrapers that "request" data from a site, this extension simply "overhears" the data the website is already sending to your screen.Layer 0 (Stealth Hook): Intercepts native API calls in the browser’s "Main World" context. It is invisible to bot detectors.Layer 1 (Schema Fallback): Reads hidden "JSON-LD" metadata (Schema.org) if the network intercept is blocked.Smart Deduplication: Uses URL hashing to ensure each hackathon has exactly one "source of truth" in the database.Part B: The Next.js PWA DashboardA modern, "Tech-Noir" web application where the extracted data is visualized.Global Sync: Once one team member visits a hackathon page, the data is instantly pushed to the cloud and becomes available to the whole team.Live Timers: Every card features a high-precision, monospace countdown timer ticking down to the millisecond.PWA (Progressive Web App): The dashboard can be "Installed" on a mobile home screen, behaving like a native mobile app without an App Store download.4. Technical ArchitectureFor the technical curious, the system is built on a High-Performance Serverless Stack:ComponentTechnologyWhy we chose itBackendFirebase / FirestoreReal-time data syncing and zero-maintenance cloud hosting.FrontendNext.js (React)Optimized for SEO, speed, and mobile responsiveness.Database APIFirestore RESTBypasses standard SDK bloat for faster extension performance.UI DesignGlassmorphismHigh-end aesthetic using semi-transparent layers and matte black tones.5. The User Journey (How it works)Passive Discovery: A team member visits a hackathon page on Unstop, Devfolio, or Devpost.Automatic Capture: The extension detects the deadline data in the background and flashes a green "✅ Saved" notification in the console.Cloud Push: The data is pushed to a secure Firestore database. The system automatically calculates the expiration date (TTL) to keep the database clean.One-Click Sharing: The user clicks "Share Timeline" in the extension popup. This generates a unique, anonymous UUID token and copies a link to the clipboard.Team Visualization: Anyone with the link opens the dashboard. They see a beautifully sorted vertical timeline of all tracked events, with live statuses (Live, Upcoming, or Ended).6. Key Features & Competitive EdgeAnti-Ban Technology: Uses "Passive Interception" to avoid Cloudflare rate-limiting.Anonymous Collaboration: No user accounts or passwords required. Access is controlled via secure, unique share tokens.Zero-Maintenance: Built-in "Time-to-Live" (TTL) policies automatically delete expired hackathons after 48 hours.Cross-Platform Support: Native support for Unstop, Devfolio, and Devpost out of the box.
